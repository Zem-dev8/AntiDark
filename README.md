# 🛡️ Anti Dark

Un prototype d'antivirus éducatif développé entièrement sur mobile via **Termux**.

## 🚀 Fonctionnalités
- Scan de dossiers spécifiques (ex: `/sdcard/Download`).
- Identification par hashage **SHA-256**.
- Base de données de signatures en format JSON.
- Système de logs pour le suivi des menaces.
